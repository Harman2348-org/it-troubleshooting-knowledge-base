# IT Troubleshooting Knowledge Base

## Overview
A beginner IT support portfolio project documenting structured troubleshooting steps for common computer and network issues.

## Goals
- Practice systematic troubleshooting and problem-solving.
- Document diagnostic steps in a clear, user-friendly format.
- Build foundational knowledge of Windows, networking, and DNS.
- Develop technical documentation skills relevant to IT support and help desk roles.

## Troubleshooting Method
1. Identify the symptoms and gather information.
2. Check likely causes, starting with the simplest.
3. Test one change at a time.
4. Verify whether the issue is resolved.
5. Document findings and follow-up steps.
