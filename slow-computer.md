# Troubleshooting: Computer Running Slowly

**Status:** Draft — verify these steps on a device before marking this guide tested.

## Symptoms
- Computer takes a long time to start.
- Apps open slowly or become unresponsive.
- Overall performance feels slower than usual.

## Questions to ask
- When did the problem start?
- Does it happen all the time or only with a specific app?
- Was new software installed or an update applied recently?
- Is there an error message?

## Diagnostic steps
1. Save work and restart the computer if it is safe to do so.
2. Check whether the slowdown affects one app or the whole system.
3. Close apps and browser tabs that are not needed.
4. Check available storage space in system settings.
5. Use the operating system's built-in task or process monitor to identify unusually high CPU, memory, or disk usage.
6. Review recently installed apps or updates if the issue began around that time.
7. Run built-in security scanning tools if malware is a reasonable concern.
8. Retest the original symptom after each change.

## Possible causes
- Too many apps running at once.
- Low available storage or memory pressure.
- A specific app or browser tab using excessive resources.
- Pending updates or a recent software change.
- Hardware limitations or a possible hardware fault.

## Resolution and verification
Record what action was taken and retest the original symptom. Do not state that the problem is fixed unless the result was verified.
